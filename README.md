# bank_loan_analysis

##  Overview
A Power BI dashboard built using SQL and bank loan data to analyze loan performance, customer trends, and key financial KPIs.

##  Tools Used
- SQL Server
- Azure Data Studio
- Power BI
- CSV Dataset

## 📊 Dashboard Features
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI
- Good vs Bad Loan Analysis
- Loan Applications by Month, Purpose, Home Ownership & Loan Status
- Interactive Filters (State, Grade, Purpose)
